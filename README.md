# Triple Hunter

> 다이아몬드를 모아 **전사 · 궁수 · 마법사**로 변신하며 끝없이 몰려오는 몬스터와 보스를 사냥하는 탑다운 픽셀 액션 게임

## 게임 소개

### 장르
탑다운 2D 픽셀 액션 · 로그라이트 서바이벌

### 어떤 게임인가요?
사방에서 몰려오는 몬스터를 처치하고, 떨어진 **다이아몬드**를 모아 레벨업하세요. 레벨업할 때마다 모은 다이아몬드의 비율에 따라 **전사 · 궁수 · 마법사** 중 하나로 변신합니다. 시간이 갈수록 몬스터는 강해지고, 2분마다 거대한 보스가 나타납니다. 최대한 오래 살아남아 높은 점수를 노려 보세요.

### 이런 재미가 있어요
- **변신하는 재미** — 근접 검술의 전사, 원거리 활의 궁수, 광역 마법의 마법사. 매 레벨업마다 역할이 바뀌어 플레이 방식이 계속 달라집니다.
- **성장하는 재미** — 역할마다 스킬 4개(Q · E · SHIFT · R)를 레벨업하고, 1단 · 2단 **진화**로 완전히 새로운 효과를 얻습니다.
- **나만의 빌드** — 시작할 때 고르는 **코어** 역할, 보스가 떨어뜨리는 조각으로 완성하는 **구슬**로 원하는 역할을 집중적으로 키울 수 있습니다.
- **보스 공략** — 일반 보스 10종과 기절 · 이동 불가 공격을 쓰는 **엘리트 보스** 5종. 바닥의 예고 범위와 돌진 경로를 읽고 피하는 손맛이 있습니다.
- **다양한 적** — 분열하는 슬라임, 멀리서 쏘는 원거리 몬스터, 맞으면 느려지는 탄을 쏘는 몬스터, 크고 강한 특수 몬스터까지.

## 조작법

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 |
| 마우스 이동 | 조준 (캐릭터가 커서 쪽을 바라봄) |
| 마우스 왼쪽 클릭 | 기본 공격 |
| `Q` `E` `SHIFT` | 역할별 스킬 |
| `R` | 특수 스킬 |
| `H` | 게임 설명 열기/닫기 (게임 일시 정지) |
| `` ` `` | 설정 |
| `1` `2` `3` | 시작 전 코어 역할 선택 |
| `F11` | 전체 화면 (Mac · Windows 앱) |

> 게임 안의 **게임 설명**(`H`)에서 규칙 · 역할 · 스킬 · 몬스터 · 보스 · 아이템을 자세히 볼 수 있습니다.
